# thurneco.se

- Sidmallar: `index.html`, `om/`, `lediga-jobb/`, `jobb/`, `styles.css`, `shared.js`, `careers.js`
- Annonsdata: `data/jobs.json` (uppdateras automatiskt, redigera inte för hand)
- Loggor och bilder: `assets/`
- Överlämning och fältkontrakt: `_handoff/`
